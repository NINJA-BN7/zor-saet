# OzimizStroy - Maishiy Texnika va Qurilish Mollari Do'koni

Zamonaviy React asosidagi E-Commerce internet do'koni.

## 🚀 Texnologiyalar
- **React 18**
- **Vite**
- **Toza CSS3 & Keyframe Animations** (Glassmorphism, 3D Parallax tilt, responsive layout)

## 📦 Imkoniyatlari
- 🛒 **Interaktiv Savat (Cart Drawer)** va promokod tizimi
- ❤️ **Sevimlilar (Wishlist Drawer)**
- ⚖️ **Taqqoslash (Compare Modal)**
- 🔍 **Canli qidiruv (Live Search Suggestions)**
- ⚡ **Flash Deals (Countdown Timer)**
- 💳 **1-bosishda xarid (Quick Buy) va to'liq rasmiylashtirish (Checkout)**
- 📱 **100% barcha qurilmalarga moslashuvchan (Responsive Design)**

## 🛠 O'rnatish va ishga tushirish
```bash
# Paketlarni o'rnatish
npm install

# Dasturni ishga tushirish
npm run dev

# Ishlab chiqarish uchun build olish
npm run build
```
